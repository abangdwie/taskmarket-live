# taskmarket-live

A public, live dashboard of [Taskmarket](https://taskmarket.dev)'s market data —
headline numbers, trends, breakdowns, heatmap and a live activity feed for
**Tempo** (chainId 4217) and **Base** (chainId 8453).

Live: **https://taskmarket-live.pages.dev**

Built for the paid Taskmarket bounty
[TSK-BRK611AN](https://taskmarket.dev) — “Build and host Taskmarket's live
market visualizer (50 OUSD)”. Made for a paid Taskmarket bounty — not an
official Taskmarket product.

## How it works

The Taskmarket API (`https://api.taskmarket.dev`) does not allow browser
requests from other websites, so the data is fetched **server-side**:

- `public/_worker.js` — a Cloudflare Pages worker (advanced mode) that fetches
  the six public endpoints for both chains, combines them (including distinct
  posters per week, computed from the paginated task list), and caches the
  result for 600 seconds in the edge cache. Same origin as the site, so the
  page reads `/api/data` directly. No key, no login, no wallet, no tracking.
- `public/index.html` — a dependency-free single-page dashboard. It reads
  `/api/data` from the worker, renders headline stats, a canvas trend chart,
  mode/status breakdowns, a mode×day heatmap, an hour-of-week heatmap, a
  live activity feed, top posters, and computed insights. It refreshes every
  10 minutes. Views are linkable (`#/trends`, `#/heatmap`, …).
- `public/og.png` — the share card (1200×630), generated by
  `scripts/og-card.py`.

Design follows the Taskmarket brand kit (ground `#12100E`, magenta `#E74079`
accent, Instrument Serif headlines, Inter Tight body).

## One-command deploy

```sh
npm run deploy
```

Needs `CLOUDFLARE_API_TOKEN` (Pages write) and `CLOUDFLARE_ACCOUNT_ID` in
the environment — on this machine the token comes from the
custom.cloudflare-direct connection (Secure Vault). The script runs
`wrangler pages deploy public` (the Cloudflare direct-upload API silently
dropped files in Nov 2026, so wrangler is the deploy path), then verifies the
site and the data endpoint. Wrangler is fetched via npx, no global install.

Preview locally (uses the live worker once deployed):

```sh
npm run preview   # http://localhost:4173
```

## Data & methods

Endpoints used, per chain: `/api/market/stats`,
`/api/stats/breakdowns`, `/api/stats/platform-time-series`,
`/api/stats/activity-heatmap`, `/api/stats/activity-feed`, `/api/tasks`.
Rewards are OUSD (1 OUSD = 1,000,000 base units). Every number on the page
can be reproduced from the API as of the page's “data as of” time.
