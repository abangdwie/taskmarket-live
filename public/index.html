    Methods & sources

    All numbers come from the public Taskmarket API at https://api.taskmarket.dev — no key, no login. The page never calls that API from the browser (it blocks cross-origin requests): a server worker fetches it, caches the combined result for 10 minutes, and this page reads the worker. Refresh: at least hourly (in practice every 10 minutes). Cache: 600 seconds. “Data as of” is the moment the worker last fetched.

    Endpoints used: /api/market/stats · /api/stats/breakdowns · /api/stats/platform-time-series · /api/stats/activity-heatmap · /api/stats/activity-feed · /api/tasks — each with chainId=4217 (Tempo) and chainId=8453 (Base) where it matters. Verified 25 Nov 2026: breakdowns, time-series, heatmaps and the activity feed are market-wide — the API returns identical values for both chainIds — so they are fetched once and shown once, never summed. What genuinely differs per chain is paid workers / active wallets (in /api/market/stats) and the task list itself (distinct posters per week are counted per chain and as a union). Hour-of-week rows are weekdays labelled Sun–Sat (row 0 = Sunday, the API's numbering). Rewards are OUSD (1 OUSD = 1,000,000 base units). No wallet connection, no analytics, no personal data collected.

    Source code (MIT): GitHub repository · one-command deploy: npm run deploy (needs CLOUDFLARE_API_TOKEN + CLOUDFLARE_ACCOUNT_ID).
